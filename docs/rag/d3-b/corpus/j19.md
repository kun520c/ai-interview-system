# HotSpot 21 G1 的 Region、并发标记与 Mixed

适用 Oracle JDK 21 HotSpot G1 的实现。暂停目标是调度软目标。

## Region 与年轻代搬迁

G1 将堆划分为等大的 Region，每个 Region 占用一段连续虚拟地址。Eden、Survivor、Old 分别由若干区域组成，区域角色可随复用变化。普通 Young GC 在一次停顿中处理年轻代区域，将存活对象复制到 Survivor 或 Old，位置受年龄等晋升条件影响。超大对象可跨多个连续 Region，其分配和回收具有特殊规则。

## 标记与老年代候选

标记周期开始时，Concurrent Start 年轻收集启动标记。并发标记在应用运行期间分析对象存活，Remark 停顿收尾，Cleanup 等阶段决定是否进入空间回收；具体日志还可能出现 Prepare Mixed 或中止标记的路径。标记结果用于识别有回收价值的老年代区域。G1 用历史收集成本及预期可回收空间等因素构建 Collection Set，尽量满足可配置暂停时间目标，但每次停顿没有严格时间上界。

## Mixed 和诊断

Mixed 收集包含年轻代与选中的一部分老年代 Region，通常通过多次停顿分摊空间回收。并发标记与 Stop-The-World 可同时存在于同一周期，搬迁、Remark 和 Cleanup 等阶段仍有停顿。分析长尾延迟时，把统一日志中的 young、concurrent mark、remark、mixed 或 full 等实际事件与业务延迟对齐，并检查老区活性、超大对象和可用空间。只看到配置的 MaxGCPauseMillis 不能推断实际停顿。
