# String 的身份、不可变性与文本构建

适用 Java SE 21 的 String、StringBuilder 和引用比较语义。

## 引用身份和内容

引用类型的 == 判断两侧是否指向同一个对象，或是否同时为 null。String.equals 判断另一对象是否也是内容相同的 String。两个对象可以内容相同而身份不同，例如比较字面量 "job" 与显式 new String("job")。相同的字符串字面量及字符串常量表达式会共享驻留实例，运行时拼接得到相同字符并不能据此推断引用身份。校验接收到的类型标识时可用 "job".equals(type)，可同时处理 type 为 null 的情况。

## 不可变值和变量重绑定

String 的字符序列在对象构造后固定。规范化输入时，text.replace('\\', '/') 通过返回值交付结果，单独调用并丢弃返回值不会更新 text。text = text.replace('\\', '/') 改变的是变量绑定，原引用持有者仍看到原内容。无匹配时 replace 可返回原对象。不要用是否分配新对象判断是否进行了规范化。

## 局部可变缓冲

批量构造可读审计摘要时，可以在一次调用中创建 StringBuilder，逐行 append，最后用 toString 得到 String；之后继续改 Builder 也不会改已返回字符串。StringBuilder 不承诺线程安全，把一个实例共享给多个异步任务时应定义整体同步边界，或者让每个任务拥有自己的缓冲，再确定性合并。短固定表达式用 + 可保持清晰，Java 语言允许编译器选择拼接实现。判断长循环的性能要以代表性长度和分配量为依据。
