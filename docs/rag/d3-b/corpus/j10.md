# 有序记录、去重与键值映射

适用 Java SE 21 List、Set、Map 的集合合同与常见哈希实现。

## 分离序列、成员和索引

处理导入事件时可用 ArrayList 记录完整处理流水，按处理顺序 append，每次尝试都有自己的位置且允许重复。Set 则维护唯一成员，先从事件提取稳定 ID，按成员相等性去重。Map 维护每个键至多一个值，按 ID 查找最新结果可在处理时 put 以更新原值。三个结构分别回答历史、成员和当前状态问题，不能从仅保留最后值的 Map 恢复完整流水。

## 首次出现和最近访问是不同顺序

默认 add 的 LinkedHashSet 保持插入顺序，重复 add 不改变已有元素位置。输入 A、B、A 时，其顺序是 A、B。Java 21 的显式定位操作 addFirst/addLast 可重新定位。HashSet 不承诺遍历顺序，即使一次运行恰好是 A、B。LinkedHashMap 可选插入顺序或访问顺序，访问顺序模式下，get 命中已有项时将其标记为最近访问，可能改变后续遍历次序。用 Map 遍历作为审计顺序前要先确定所需的顺序合同。

## 晚到事件与重复记录

若 A 的版本 9 先处理，版本 7 晚到，简单 put 得到最后处理的版本 7。若业务要求保留最大版本，更新必须显式比较版本，例如串行处理时用 merge 选出更高版本并规定相同版本的处理方式。Set 去重若只认 ID，将 A 的后续版本视为已出现，无法代替 Map 的更新逻辑。并发场景还需采用合适的原子更新或外部协调。
