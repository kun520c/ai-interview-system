# Phase 5A frozen semantic benchmark review

38 个中文合成候选人回答；30 MAIN + 8 FOLLOW_UP。Gold 在零 Provider 调用时按冻结评分点逐项确定。不是由真实人类评委独立标注的数据集。

严格标准：多条件评分点须有足以支持其核心条件的正确内容；明确错误或后文否定不能覆盖。未知、离题、注入指令均无技术覆盖。FOLLOW_UP 合并主答已有支持与追问修复。

BOUNDARY 刻意测试条件边界并保留一个明确未回答的维度；并不承诺所有 BOUNDARY 满分。FOLLOW_UP 分数带 0..100 仅作描述，硬要求是四对修复严格高于失败修复。

评分点位置仅供下面审查说明；实际 JSON 全部使用数据库 ID。
