## 指标与实际链路

`EvaluationRagQueryBuilder → Embedding/Milvus Top5 → KnowledgeRetrievalService` 的 MySQL READY、ACTIVE、文档版本、embedding model 和 profile 资格校验 → `EvaluationRetrievalAdapter → EvaluationPromptBuilder`。生产编排固定请求 5 条；evaluation 默认 cosine 阈值关闭，仓库内 `rag-p1` 可显式启用 0.70，其他外部配置也可覆盖。生产 PromptBuilder 对 evidence 逐条完整序列化，保留原始 rank，当前无额外上限、正文截断或去重。空证据分支要求模型仍按题目、参考答案、评分点评价；外部异常并不等同空结果。相同检索结果传递给轨迹写入和 Prompt。旧评测未写业务轨迹；真实持久轨迹需结合实际 HTTP 场景单独核对。

原“Prompt 直接相关率”是所有查询中实际序列化 DIRECT 条目数 / 所有实际条目数的 **micro query–chunk 精度**，包含无答案查询；不是评分点覆盖、token 比例或固定五条分母。macro 是各非空查询精度的均值；空证据 precision 为 N/A，须同时报告空率、命中和错误拒绝。重复 chunk 保留分母，仅第一次可记 DIRECT。固定分母 P@5 与正例 Hit/MRR 分开，未返回位置按零，独立于 Prompt 实际长度。当前每次恰好五条，故在同一查询分组内两者数值偶然一致。公开正例 P@5 67/240=27.92%，含负例的 Prompt 精度 67/300=22.33%；独立正例 P@5 21/90=23.33%，全体 Prompt 为 21/120=17.50%；生产 MAIN 为 75/315=23.81%，追问 9/45=20%。原口径重算吻合，不需要改写历史指标。
