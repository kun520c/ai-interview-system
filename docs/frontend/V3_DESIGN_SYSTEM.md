# Technical Interview Studio V3 · Design System

状态：V3 实现规范。日期：2026-10-17。

V2 的 `DESIGN_SYSTEM.md` 保留为历史记录。视觉变更以本文件为准，行为约束继续遵守 PRODUCT_UX_SPEC、STATE_MODEL 和实际已测试代码。

## 核心方向

以浅色训练工作室组织内容：明确的一项主操作、舒适的作答空间、可扫描的评价和有证据的复盘。英文 studio 标识只用于品牌和少量元信息，操作仍使用中文。

不增加仪表盘 KPI、未来题目、学习时长、排行榜或虚构完成率。题目与评价来自现有响应。主问题进度仍由 completed / planned 计算。

## 字体与密度

系统字体优先，不加载外部字体。Inter 在本机存在时使用，否则回退 Segoe UI、苹方、微软雅黑。中文标题 25–30px，当前题目桌面 23px／手机 19px，长回答 15px、1.85 行高，评价／报告正文 13–14px、1.85 行高。辅助信息 11–13px；关键操作至少 14px。总分 46px／报告 56px，使用 tabular monospace，保留小数原值。

一张表面表示一个任务或信息组。正文段落不再各套大型卡片；反馈分组通过标题、细边线和语义左边界区分。五维原始分数均为 0–20，细条宽度为 `score / 20`；显示原始分数，总分直接显示服务端值。细条为装饰并设置 aria-hidden，不重复向读屏器播报。

## 共用控件状态

按钮：44px 最小高度；primary 表示当前主操作，ghost 表示次操作，danger 保留真实危险语义。disabled 仍为原生禁用；loading 同时有 spinner、文字和 aria-busy。hover 只改变表面／颜色，不移动布局。

输入：白底、1px 明确边框、10px 圆角、蓝色 focus ring。invalid 使用错误边框并保留 aria-invalid / describedby。readonly 使用浅灰底，不能暗示可编辑。密码可见性、标签、自动填充属性全部沿用。

状态提示：局部语义底色、左边界、真实错误文字、原有 alert/status。空状态：图标、标题、简短说明和实际可执行入口；无样例成绩。骨架只在真实请求未完成时出现。尊重 `prefers-reduced-motion`，禁用非必要动画和过渡。

## 页面层级

| 页面 | 阅读／操作顺序 |
|---|---|
| 面试 P0 | focus header → 当前进度和题目 → 作答；提交后同一右栏改为评价 → 总分与评级 → 五维 → 优势／缺失／修正 → 显式继续 |
| 工作台 P1 | 用户问候 → 开始或继续当前面试 → 低优先级流程说明 → 最近完成记录 |
| 报告 P1 | 综合分与评级 + 本场说明 → 优势／薄弱点 → 编号建议 → 问答评价证据 |
| 开始 P2 | 三个同等地位的 native radio → 确认开始 → 流程说明；无默认选择、无推荐 |
| 认证／历史 P2 | 统一品牌、输入与主按钮；真实记录按行展示，保留报告异常与空值提示 |
| 管理 P3 | 页面标题／操作 → 筛选器 → 题库表格；题目与评分点表单、知识上传与本机近期记录分组 |

难度文案：EASY「基础巩固」、MEDIUM「综合进阶」、HARD「深度挑战」。枚举、题目数量和完整领域不变。

报告 API 没有整体五维字段，因此不计算虚构聚合图。真实五维细条仅位于每道问题的评价中（Session / Detail / Report evidence 共用组件）。

## 响应式与无障碍

1440：固定可滚动白色边栏、工作台主操作与流程并排、报告双栏分组；面试独立 39/61 双栏，问题与反馈可以分别滚动。

1024：侧栏收至 204px，工作台按内容重排；面试保留 42/58 双栏，不缩小作答正文字号；认证切单栏。页面按钮允许换行。

390：产品页使用现有顶部菜单；面试为可滚动的「题目 → 作答／评价」单栏。dock 是滚动区域的同级元素，参与 flex 布局，不覆盖最后一段内容；safe-area 为底部留空间。管理员表格沿用手机行项目模式，表单单列。

保留 skip link、原生 radio / button / input、语义标题层级、当前导航 aria-current、可见键盘焦点、菜单焦点恢复与 Escape。长题目、技术 token、回答和错误提示均允许换行。图标只做辅助，不替代文字。

## 与 V2 的变化

V2 的 8–10px 面板、近乎无阴影与平铺文字层次调整为控件／面板分级圆角和有限阴影，增强任务空间辨识度。原先完全禁止渐变的视觉决定改为受控的单 token 局部浅色层；答题输入区仍纯白。V2 的报告无图规则调整为允许展示已有五维真实数据的细条，不引入统计或图表依赖。

顺序面试、只显示当前题、评价确认、requestId、恢复、权限与所有真实失败分支均保持。视觉逻辑只位于组件模板／样式；没有修改 API、router、store、composable 或 storage。
